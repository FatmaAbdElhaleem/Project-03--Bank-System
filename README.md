# Bank Management System (C++)

## 📌 Overview

This is a console Bank Management System built using C++.  

It was built as part of my learning journey through the Programming Advices roadmap (Course 7 & Course 8).  

The system provides client management, transaction processing, user authentication, and user management with permission-based access control.

All data is stored using file handling to simulate a real banking system.

## 🚀 Features

### 🔐 Authentication
- User Login
- User Logout

### 🛡️ Authorization
- User Permissions
- Access Control

### 👥 User Management
- Show Users List
- Add New User
- Delete User
- Update User Information
- Find User

### 👤 Client Management

* Show all clients
* Add new client
* Delete client
* Update client information
* Find client by account number

### 💰 Transactions

* Deposit money
* Withdraw money (with balance validation)
* Show total balances

## 🛠️ Technologies Used

* C++
* File Handling (`fstream`)
* STL (`vector`, `string`)
* Structures (`struct`)
* Console Application

---

## 📂 Project Structure

* `BankSystem.cpp` — Main application source code.
* `ClientList.txt` — Stores client records.
* `Users.txt` — Stores users and their permissions.
  
---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/bank-system.git
```

2. Open the project in any C++ compiler (e.g., CodeBlocks, Visual Studio)

3. Make sure `ClientList.txt` exists in the same directory

4. Run the program
